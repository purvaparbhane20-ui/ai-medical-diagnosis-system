🩺 AI Medical Diagnosis System

📌 Project Overview

The AI Medical Diagnosis System is a Python-based mini project that analyzes user-provided symptoms and suggests possible health conditions using predefined rules and "if-else" statements.

This project demonstrates a basic rule-based approach to applying Artificial Intelligence concepts in healthcare.

🎯 Objectives

- To understand the application of AI concepts in healthcare.
- To analyze symptoms using Python conditional statements.
- To develop a simple rule-based decision-making system.
- To improve Python programming skills.

🛠️ Technologies Used

- Programming Language: Python
- Concepts: Conditional Statements ("if-else"), Rule-Based Logic

✨ Features

- Accepts symptoms from the user.
- Analyzes symptoms using predefined rules.
- Suggests possible conditions based on the implemented logic.
- Displays results in a simple format.

⚙️ Working Principle

1. The program starts and asks the user to enter symptoms.
2. The user enters symptoms.
3. The system checks the symptoms against predefined rules.
4. The program displays a possible condition based on the matching rule.

🔄 System Workflow

Start → Enter Symptoms → Check Predefined Rules → Display Result → End

▶️ How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the Python file using:

python main.py

Note: Replace "main.py" with your actual Python filename if it is different.
