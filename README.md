AI Medical Diagnosis System

A Python-based AI mini project that analyzes user-provided symptoms using predefined rules and suggests possible health conditions.

Project Overview

This project demonstrates a basic application of artificial intelligence concepts in healthcare. It uses Python conditional statements ("if-else") to evaluate symptoms and provide preliminary condition suggestions.

Objectives

- Explore the application of AI concepts in healthcare.
- Understand rule-based decision-making using Python.
- Analyze symptoms using predefined conditions.
- Build a beginner-friendly healthcare-related programming project.

Technologies Used

- Python
- Conditional statements ("if-else")

Features

- Accepts symptoms from the user.
- Evaluates symptoms using predefined rules.
- Displays possible condition suggestions based on implemented logic.

How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the Python file:

python main.py

Learning Outcomes

- Improved Python programming skills.
- Practical understanding of conditional logic.
- Exploration of rule-based systems in healthcare.
